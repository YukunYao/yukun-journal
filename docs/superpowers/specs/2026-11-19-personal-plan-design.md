# Personal plan design

## Intent

Let a visitor write a flexible plan without an account or AI service. The journal remains the primary product. A plan is optional and never scored against daily records.

## Approach

Store four short, user-authored sections in the active journal: food rhythm, movement, recovery, and this week's focus. Show an editable form on AI Plan and a small, read-only focus on My Day. Saving a blank form clears the plan. Export, restore, and browser deletion include it because they already operate on the entire journal.

This extends the existing `JournalState` and IndexedDB/cloud snapshot model. A separate plan database or generated starter text would add complexity and could imply prescribed health advice. AI generation remains gated behind the existing service and review controls.

## Boundaries

- No calorie target, weight-loss pace, AI inference, or completion score is generated by this feature.
- The page uses the existing English editorial typography and restrained paper styling.
- Older saved journals normalize to no personal plan. A backup with a plan must validate before replacement.
- Saving to a cloud journal uses the existing authenticated save flow; anonymous users save only in this browser.
